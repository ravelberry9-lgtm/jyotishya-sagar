## Pipeline (reproducible)

1. `pdftotext -layout brihajjAtakam.pdf brihat-jataka-sanskrit.txt` — clean Devanāgarī extraction.
2. Python parser (run from `bphs/`) splits Sanskrit by chapter ordinal markers and verse-end `॥ N ॥` markers → `brihat-jataka-sanskrit.json` (409 verses).
3. Python parser walks `brihat-jataka-source.txt` for `Sloka N.—...` markers under chapter context → `brihat-jataka-english.json` (295 verses).
4. Merge: combine Sanskrit + English + chapter titles + Telugu summaries into `brihat-jataka-merged.json`.
5. JS code generator emits `brihat-jataka-data.js` with the proper IIFE wrapper and the GRANTHAS structure.
6. `node --check brihat-jataka-data.js` passes — file is valid JavaScript.
